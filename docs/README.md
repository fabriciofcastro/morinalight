# Documentação MORINA Light

Referências canônicas para manter agentes humanos e IAs alinhados ao blueprint.

- [`MANIFESTO.md`](./MANIFESTO.md): princípios de produto/engenharia e definição de pronto.
- [`DOCS_STANDARDS.md`](./DOCS_STANDARDS.md): estrutura obrigatória para qualquer documento novo.
- [`CURSOR_START.md`](./CURSOR_START.md): regras de uso do Cursor/LLMs, economia de tokens e MCPs.
- [`MORINA Blueprint Operacional.md`](./MORINA%20Blueprint%20Operacional.md): visão expandida com design system, fluxo operacional e backlog.
- [`morina_operacional_plus*.md`](./): incrementos e anexos do blueprint; usar como extensão quando necessário.
- [`usage/login.md`](./usage/login.md): guia rápido do portal de login, regras e KPIs.
- [`usage/project-overview.md`](./usage/project-overview.md): narrativa da home e roadmap visual.
- [`usage/personalization.md`](./usage/personalization.md): manual de personalização visual avançada (tema, vídeo e logo).
- [`decisions/0001-auth-portal.md`](./decisions/0001-auth-portal.md): decisão arquitetural sobre o portal de acesso.
- [`presentations/login-demo.md`](./presentations/login-demo.md): roteiro de demonstração para impressionar a gerência.

### Como usar

1. Leia o manifesto antes de iniciar qualquer tarefa.
2. Estruture novos documentos seguindo `DOCS_STANDARDS.md`.
3. Configure seu ambiente Cursor com base em `CURSOR_START.md`.
4. Atualize o backlog e as decisões arquiteturais via ADRs referenciados aqui.
