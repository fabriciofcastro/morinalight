# Padrões de Documentação MORINA

Cada documento segue esta estrutura:

1. Contexto e motivação.
2. Escopo e não-escopo.
3. Modelo de domínio e entidades.
4. Regras de negócio (numéricas e claras).
5. Contratos Zod/DTO.
6. Eventos (nome + payload).
7. Fluxos e diagramas simples.
8. KPIs e SLIs.
9. Checklist DoD.

**Guidelines**

- Evitar ambiguidade.
- Sempre exemplos input→output.
- Cada mudança relevante vira ADR em docs/decisions.
